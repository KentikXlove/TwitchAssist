# 📘 Руководство по созданию кастомных стилей для чат-оверлея

Этот документ содержит полную инструкцию для разработчиков и дизайнеров, которые хотят изменить внешний вид чат-оверлея под свои нужды. Оверлей построен на HTML/CSS/JS и поддерживает гибкую настройку стилей через встроенный механизм.

## 📦 Структура DOM

Основные элементы, к которым можно применять стили:

| Селектор / Класс | Описание |
|------------------|----------|
| `#messages` | Контейнер всех сообщений (имеет вертикальный скролл) |
| `.chat-msg` | Отдельное сообщение (флекс-контейнер) |
| `.chat-avatar` | Аватар пользователя (круглое изображение) |
| `.chat-badges` | Контейнер для бэджей (значков ролей) |
| `.chat-badge` | Отдельный значок (изображение) |
| `.chat-username` | Имя пользователя (цвет задаётся через атрибут `style`) |
| `.chat-time` | Время отправки сообщения (по умолчанию скрыто, появляется при наведении, если не переопределено) |
| `.chat-emote` | Изображение смайлика/эмоции (вставляется через `img`) |

### Пример HTML-структуры одного сообщения:
```html
<div class="chat-msg">
    <img class="chat-avatar" src="..." alt="username">
    <span class="chat-badges">
        <img class="chat-badge" src="...">
    </span>
    <span class="chat-username" style="color:#FF0000;">Username</span>
    : <span>Текст сообщения с <img class="chat-emote" src="..."></span>
    <span class="chat-time">12:34:56</span>
</div>
```

## 🛠 Способы применения кастомных стилей

Существует два способа загрузить свои стили:

### 1. Через настройки оверлея (API конфигурации)
В объекте `overlay` (получаемый по `/api/config`) доступны поля:
- **`custom_css`** – строка с произвольным CSS-кодом (вставляется в `<style id="custom-style">`).
- **`style`** – имя предустановленного стиля (загружается с сервера по `/api/style?name=...`). Если указано, то `custom_css` игнорируется (кроме случая ошибки загрузки).

Пример конфигурации:
```json
{
  "overlay": {
    "custom_css": ".chat-msg { background: rgba(0,0,0,0.7); border-radius: 10px; }",
    "style": "dark_theme"
  }
}
```

> **Приоритет:** если `style` задан и не равен `"custom"`, то загружается CSS с сервера. Иначе используется `custom_css`. Если сервер не вернул стиль, подставляется `custom_css`.

### 2. Прямое редактирование файла (для локальной разработки)
Вы можете изменить стили внутри тега `<style>` в файле `index.html` или дополнить их через инспектор браузера для быстрого тестирования.

## 🎨 Доступные CSS-переменные

Для удобства в корне документа определены переменные, которые можно переопределять:

| Переменная | Назначение | Значение по умолчанию |
|------------|------------|----------------------|
| `--avatar-size` | Размер аватара (ширина/высота) | `28px` (задаётся через `avatar_size` в конфиге) |
| `--anim-speed` | Скорость анимаций (если они включены) | `0.3s` (задаётся через `animation.speed`) |

Пример использования:
```css
.chat-msg {
    --avatar-size: 40px; /* увеличим аватарки */
}
```

## 🧩 Рекомендации по стилизации

### Базовое оформление сообщения
```css
.chat-msg {
    background: rgba(20, 20, 30, 0.8);
    border-radius: 12px;
    padding: 8px 16px;
    margin-bottom: 6px;
    border-left: 4px solid #7c5cfc;
}
```

### Цвет имени (переопределяется через JS, но вы можете задать глобально)
```css
.chat-username {
    color: #ffcc00 !important; /* если хотите перебить динамический цвет */
}
```

### Скрытие времени (или изменение позиции)
```css
.chat-time {
    display: none; /* полностью скрыть */
    /* или */
    margin-left: 10px;
    color: #aaa;
}
```

### Аватары
```css
.chat-avatar {
    border-radius: 50%;
    border: 2px solid #fff;
    box-shadow: 0 0 5px rgba(0,0,0,0.5);
}
```

### Бэйджи
```css
.chat-badge {
    height: 20px;
    filter: drop-shadow(0 0 2px gold);
}
```

### Смайлики (эмодзи)
```css
.chat-emote {
    height: 1.6em;
    vertical-align: middle;
}
```

### Контейнер сообщений (скролл)
```css
#messages {
    background: transparent; /* или задать фон для всей области */
    padding: 10px 20px;
    scroll-behavior: smooth; /* уже включено через JS */
}
```

## 🌀 Анимации (если вы их вернули)

По умолчанию в оверлее предусмотрены анимации входа/выхода. В минимальной версии они удалены, но вы можете добавить свои. Для этого используйте классы:

- **Вход:** `.anim-fade`, `.anim-slide`, `.anim-pop`, `.anim-bounce`, `.anim-glow`, `.anim-flip`
- **Выход:** `.exit-fade`, `.exit-slide`, `.exit-pop`, `.exit-bounce`, `.exit-glow`, `.exit-flip`

Пример добавления своей анимации:
```css
@keyframes mySlideIn {
    from { opacity: 0; transform: translateX(-50px); }
    to { opacity: 1; transform: translateX(0); }
}
.anim-myslide {
    animation: mySlideIn 0.4s ease-out forwards;
}
```
Затем укажите `entry: "myslide"` в настройках `animation`.

## 📐 Адаптивность

Оверлей автоматически подстраивается под размер окна. Для мобильных экранов можно использовать медиа-запросы:

```css
@media (max-width: 600px) {
    .chat-msg {
        font-size: 12px;
        padding: 4px 8px;
    }
    .chat-avatar {
        width: 24px;
        height: 24px;
    }
}
```

## 📦 Пример полноценного кастомного стиля

Создадим стиль с затемнённым фоном, скруглёнными углами, тенью и сменой цвета при наведении:

```css
/* custom-style.css */
body {
    background: transparent;
    font-family: 'Comic Sans MS', cursive, sans-serif;
}

#messages {
    background: rgba(0, 0, 0, 0.6);
    border-radius: 16px;
    padding: 12px;
    backdrop-filter: blur(6px);
    box-shadow: 0 8px 32px rgba(0,0,0,0.4);
}

.chat-msg {
    background: rgba(255, 255, 255, 0.05);
    border-radius: 20px;
    padding: 10px 18px;
    margin-bottom: 8px;
    transition: background 0.2s, transform 0.2s;
    border: 1px solid rgba(255,255,255,0.1);
}
.chat-msg:hover {
    background: rgba(255, 255, 255, 0.15);
    transform: scale(1.02);
}

.chat-username {
    font-weight: bold;
    text-shadow: 0 0 8px currentColor;
}

.chat-time {
    opacity: 0.6;
    font-size: 9px;
    margin-left: 12px;
}

.chat-avatar {
    border: 2px solid #fff;
    box-shadow: 0 0 12px rgba(0, 150, 255, 0.3);
}

.chat-badge {
    height: 22px;
    margin-right: 2px;
}
```

## 🚀 Как применить свой стиль через интерфейс

1. Перейдите в настройки оверлея (ваша админ-панель).
2. В разделе «Оверлей» найдите поле **«Пользовательский CSS»**.
3. Вставьте туда свой CSS-код (или укажите имя стиля, если он загружен на сервер).
4. Сохраните настройки – изменения применятся мгновенно без перезагрузки страницы (благодаря сокет-событию `settings_updated`).

## ⚠️ Важные замечания

- Все пользовательские стили вставляются в `<style id="custom-style">`, поэтому они имеют приоритет над базовыми (при одинаковой специфичности).
- Для изменения аватаров и их размера лучше использовать переменную `--avatar-size` или настройки оверлея, чтобы JS корректно обновлял размеры.
- Если вы используете `!important`, будьте осторожны – это может усложнить дальнейшую кастомизацию.
- Скролл-полоса скрыта по умолчанию, но вы можете её показать, переопределив `#messages::-webkit-scrollbar` (для Chrome) и `scrollbar-width` (для Firefox).
- Стили загружаются асинхронно, поэтому при первом рендере может быть кратковременное мерцание – это нормально.
